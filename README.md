 Introduction

 ### Instructions
 > First of all we will solder wire on every solder pad and then make a bunch of them together.
 > now comes the MCU U hve to castellated solder it on top of the board or can use very low height header pins. we can have access to wire below the MCU and then connect them their respective components. 
 > Then Place components using supports provided using screws and tape/glue as required.
 > Use a double sided tape to mount battery here
 > 



## Code
This requires basic firmware code u can compile and flash it in MCU using Platform.io (a extension in VS code) or using Thonny (IDE)
